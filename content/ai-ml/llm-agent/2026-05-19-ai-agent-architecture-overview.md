## AI Agent란?

AI Agent는 LLM을 핵심 추론 엔진으로 사용하면서, 외부 도구(Tool)를 호출하고 환경과 상호작용하여 목표를 달성하는 시스템이다.

## 핵심 구성 요소

```
┌─────────────────────────┐
│       AI Agent          │
├─────────────────────────┤
│  LLM (추론 엔진)        │
│  Memory (단기/장기)      │
│  Tools (외부 도구)       │
│  Planning (계획 수립)    │
└─────────────────────────┘
```

### 1. LLM (Large Language Model)
에이전트의 "두뇌" 역할. 사용자 의도를 이해하고, 다음 행동을 결정한다.

### 2. Memory
- **단기 메모리**: 현재 대화 컨텍스트
- **장기 메모리**: 벡터 DB 등을 활용한 지식 저장

### 3. Tools
외부 API, 데이터베이스, 코드 실행 등 실제 작업을 수행하는 도구들.

### 4. Planning
복잡한 작업을 하위 작업으로 분해하고, 실행 순서를 결정한다.

## ReAct 패턴

가장 널리 사용되는 에이전트 패턴:

1. **Reason** (추론): 현재 상황을 분석
2. **Act** (행동): 적절한 도구를 선택하여 실행
3. **Observe** (관찰): 결과를 확인하고 다음 단계 결정

> 이 내용은 추후 실제 프로젝트 경험과 함께 더 구체적으로 업데이트할 예정이다.
